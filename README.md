# 🎖️ Ad-Matai — עד מתי?

יום שישי, התיק כבר ארוז, ושער הבסיס ממש מעבר לפינה. ואז המפקד נזכר שיש עוד כמה משימות. **עד מתי?** הוא משחק דו־ממדי קומי לשחקן יחיד, שבו מנסים לסיים את המטלות ולצאת הביתה לפני שסוגרים שבת.

**הגרסה הנוכחית היא אב־טיפוס של המטווח.** היא נפתחת ישירות במשחקון. הצעידה, תורנות המטבח והריצה שמחברת בין המשחקונים מתוארות בהמשך.

## 🎯 המטווח

![סיבוב פעיל במטווח עם מטרות אדומות, מגן ירוק, טיימר וניקוד](images/shooting-range-screenshot.png)

*צילום מסך מתוך סיבוב במטווח.*

1. לוחצים על **Tap to Play** כדי להתחיל. במחשב משתמשים בעכבר, ובטלפון נוגעים במסך.
2. פוגעים במטרות האדומות כשהן מופיעות וצוברים נקודות. פגיעה במטרה ירוקה מורידה **3 שניות** מהטיימר.
3. הסיבוב מתחיל עם **30 שניות**. כשהזמן נגמר, מופיעים הניקוד הסופי ו־**YOU WIN** אם הגעתם ל־**350 נקודות** לפחות, או **GAME OVER**. לחצו על **Play Again** לסיבוב נוסף.

## 🚧 המשחקונים הבאים

| משחקון | מה מתוכנן | סטטוס |
| --- | --- | --- |
| **צעידה** | שולטים בזוג הרגליים שבמרכז השורה ומחליפים בין רגל שמאל לימין לפי הקצב. | בתכנון |
| **תורנות מטבח** | רואים רצף של מאכלים ובוחרים אותם מחדש באותו סדר. | בתכנון |
| **הדרך הביתה** | משלימים את שלושת המשחקונים ברצף כדי לקבל אישור יציאה. כישלון במשימה מסיים את הריצה. | בתכנון |

![תקריב של שלושה זוגות מגפיים צועדים משמאל ותורנות מטבח מימין](images/marching-kitchen-concept.png)

*איור קונספט לצעידה ולתורנות המטבח, שנוצר באמצעות AI כדי להמחיש את המשחקונים המתוכננים.*
